# Vocax

A multilingual AI voice assistant for everyday life. *Your voice. Your world.*

Built with Flutter. Listens in English, Afaan Oromo or Amharic (when the language is installed in the phone's speech service) and answers by voice.

## Project structure

```
Vocax/
├── .github/workflows/flutter-build.yml   CI: analyze, test, build the APK
├── android/                              Android project (generated by CI)
├── assets/                               images and icons
├── lib/
│   ├── main.dart                         entry point
│   ├── app.dart                          MaterialApp and theme
│   ├── theme.dart                        colors, gradient, background
│   ├── screens/
│   │   ├── welcome_screen.dart           "Get Started" screen
│   │   └── home_screen.dart              listening / speaking screen
│   ├── services/
│   │   ├── voice_service.dart            speech recognition + text to speech
│   │   ├── command_handler.dart          what Vocax does with what you say
│   │   ├── app_launcher.dart             opens apps and the dialer
│   │   ├── contact_service.dart          contact lookup (placeholder)
│   │   └── language_service.dart         supported languages

│   └── widgets/                          reusable UI pieces

├── pubspec.yaml

```

## Voice commands

| Say | Vocax does |
| --- | --- |
| "Hello Vocax" | greets you |
| "How are you" / "What is your name" | answers |
| "Open YouTube" (also Google, Maps, Gmail, WhatsApp, Telegram, Facebook) | opens it |
| "Call <name>" | not available yet, needs contact access |
| anything else | repeats what it heard |

## Build

Push to `main` (or run the workflow by hand). GitHub Actions builds the APK and uploads it as the `vocax-android-apk` artifact.

To work on a computer: run `flutter create --platforms=android .` once in this folder to generate `android/`, add the microphone permission to `AndroidManifest.xml`, then `flutter run`.
