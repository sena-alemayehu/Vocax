# Vocax

A multilingual AI voice assistant for everyday life. *Your voice. Your world.*

Built with Flutter. Listens in English, Amharic, Afaan Oromoo, French or Spanish (when the language is installed in the phone's speech service) and answers by voice. Spoken replies are still English only.

## Features

- Side menu: language, dark mode switch, voice commands list, About.
- Select Language screen (English, Amharic, Afaan Oromoo, Français, Español) and a quick dropdown in the top bar, remembered between launches.
- Light and dark theme, toggled from the top bar or the menu, remembered between launches.
- Vocax app icon (adaptive icon on Android) generated from `assets/icons`.

## Voice commands

| Say | Vocax does |
| --- | --- |
| "Hello Vocax" | greets you |
| "How are you" / "What is your name" | answers |
| "Open YouTube" (also Google, Maps, Gmail, WhatsApp, Telegram, Facebook) | opens it |
| "Call <name>" | not available yet, needs contact access |
| anything else | repeats what it heard |

## App icon

The icon comes from `assets/icons/app_icon.png` (full icon) and `assets/icons/app_icon_foreground.png` (wave on transparent, for Android adaptive icons) using `flutter_launcher_icons`. To change it, replace those two files; CI regenerates the launcher icons on every build. On a computer you can run `dart run flutter_launcher_icons` yourself.

## Build

Push to `main` (or run the workflow by hand). GitHub Actions builds the APK and uploads it as the `vocax-android-apk` artifact.

To work on a computer: run `flutter create --platforms=android .` once in this folder to generate `android/`, add the microphone permission to `AndroidManifest.xml`, then `flutter pub get`, `dart run flutter_launcher_icons` and `flutter run`.
